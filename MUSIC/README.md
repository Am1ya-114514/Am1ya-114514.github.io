# MUSIC —— 阿巴怪电台的歌单

**这里就是加歌的地方。** 把音频文件直接丢进这个文件夹（`F:\Github\Am1ya-114514.github.io\MUSIC\`），
然后跑一次构建，歌就会出现在首页右下角的「阿巴怪电台」里。

## 最短流程

1. 把 `.mp3`（也支持 `.flac` `.wav` `.ogg` `.m4a`）放进本文件夹；
2. 在仓库根目录执行：

   ```powershell
   $env:PATH = "F:\dev\nodejs;$env:PATH"
   & "F:\dev\nodejs\npm.cmd" run build
   ```

3. 推上去：

   ```powershell
   git add -A
   git commit -m "music: 更新歌单"
   git push
   ```

`npm run build` 第一步 `generate:assets` 会自动把这里的音频复制到
`public/themes/fuyukawa-kagari/music/` 并重写 `manifest.json`——**不要手动改 manifest**，
它是构建产物。

## 播放顺序

默认按文件名排，并且会把开头的序号当作顺序、从显示的歌名里去掉：

| 文件名 | 显示 | 顺序 |
| --- | --- | --- |
| `01-最后一页.mp3` | 最后一页 | 1 |
| `02-雨爱.mp3` | 雨爱 | 2 |
| `03-瞬.mp3` | 瞬 | 3 |

序号后面可以用 `-`、`_`、`.`、`、`、`)` 任意一种分隔。没有序号的文件排在有序号的后面，
按中文拼音排序。

想完全自己定顺序、或者要带上歌手名，就在本文件夹里加一个 `playlist.json`：

```json
[
  { "file": "最后一页.mp3", "title": "最后一页", "artist": "江语晨" },
  { "file": "雨爱.mp3", "title": "雨爱", "artist": "杨丞琳" },
  { "file": "瞬.mp3", "title": "瞬" }
]
```

列在里面的文件会按这个顺序排在最前，没列到的按上面的规则接在后面。
`title` 和 `artist` 都可以省，省了就用文件名。

## 播放行为

- 打开任意一页就会从上一次听到的位置自动续播；一次放完接下一首，最后一首放完循环回第一首。
- 浏览器规定「没有用户操作就不许出声」。第一次访问如果被拦下，播放器会在你
  **第一次点击 / 滚动 / 按键**时自动开始——不用去点播放按钮。
- 想彻底关掉自动播放：在页面上**右键**（手机长按）→「♫ 进站续播：关」。
